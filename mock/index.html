モックで試せること

  • ツリーのファイルをターミナルへドラッグパスを入力。フォルダなら cd
  • ツリーのファイルをデスクトップへドラッグ種類に合ったウィンドウで開く
  • ssh db01 screen -r mc docker exec -it web bash mysql自動でウィンドウに移る
  • tail -f mc/logs/latest.log python3 topターミナルの上のつまみをデスクトップへドラッグ
  • セッションのウィンドウをターミナルへドラッグターミナルに戻る
  • ウィンドウを左右の端や上の端へドラッグ半分の大きさや最大化
  • PC のファイルやフォルダを左のファイルツリーへドラッグ落とした先のフォルダへアップロード。同じ名前があれば上書きするか聞く
  • リソース監視の項目をクリックCPU やメモリを多く使っているプロセス、大きいフォルダ、接続中の相手を見る
  • 下のタブをドラッグ並べ替え。タブの × で閉じる
  • タスクバーの Dockerコンテナの起動・停止・シェル・ログ、イメージとボリューム。コンテナをデスクトップへドラッグするとシェルを開く
  • 上の欄の sudoON にするとパスワードを聞く。何を入れても通る。ON の間はサービスの操作、ホームの外のファイル、root のファイルの変更ができる
  • ツリーの右クリック切り取り・コピー・貼り付け・名前の変更・削除・パスのコピー・プロパティ。Ctrl+C / X / V、F2、Delete も使える。削除したものはゴミ箱から戻せる
  • ツリーの上の ↑ホームの外へ移る (sudo モードのとき)
  • サービスの「ログ」journalctl の出力を開く
  • 圧縮ファイルの … から「解凍して閲覧」中身の一覧を出し、テキストのファイルは開いて読める
  • 一番下の欄の CPU・メモリ・ネットワーク押すとリソース監視の詳細を開く
  • 左の欄の一番下の歯車テーマ、アクセントの色、ターミナルの配色、操作の設定
  • 上の + から接続router を選ぶと、エージェントを入れられないときの流れになる
